## 자동 테스트 범위의 해석

테스트 코드는 Python으로 게임 규칙을 흉내 내지 않습니다. 공식 Luau 0.743 실행 파일에서 실제 모듈을 불러옵니다. ProfileStore 테스트만 Roblox 서비스·task·require를 모의 어댑터로 주입합니다. 소스의 저장 알고리즘 자체는 그대로 실행합니다.

자동 테스트는 실제 엔진 통신·Replica 업데이트·모델 충돌·Font 렌더링·모바일 입력을 실행하지 않습니다. 또한 Studio 디버그 도구로 받은 알은 낚시의 자연 획득 실증이 아닙니다.

최종 성공 기준인 **Studio에서 실제로 전체 루프를 플레이할 수 있음**은 `STUDIO_TEST_PLAN.md`를 실행하여 확인해야 합니다. 해당 검증을 이미 마쳤다는 의미로 이 결과표를 사용하지 마세요.
