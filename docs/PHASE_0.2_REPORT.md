# FILAMENT 0.2 — 구현 및 기능별 테스트 결과

2026-11-02 (KST). 판정은 **구현·자동 검사·빌드 완료, 실제 Studio 승인 전**입니다. 실제 Roblox Studio가 없는 Linux CLI 환경에서 작업했습니다. 게임 전체의 실제 플레이 PASS나 시각 QA PASS를 주장하지 않습니다.

## 변경과 기준

기준 main을 fresh fetch하여 `857fa5c95357908fa022e6f61417b6e773432765`에서 새 브랜치 `feature/fishing-functional-blockout`을 만들었습니다. 0.1.1 브랜치의 `4107562a2f31a827e4a0b8885cfe3fbfc5733030`과 Draft PR #1, 기존 0.1 빌드는 보존했습니다. 다른 프로젝트를 변경하거나 main에 병합하지 않았습니다.

콘셉트 아트 「수족관 정원이 있는 낚시 마을」을 확인하고 **남쪽 입구 → 중앙 연못·부두 / 왼쪽 아래 상점 / 왼쪽 위 공방 / 북쪽 뒤편 수족관** 관계만 반영했습니다. 건물·지붕·꽃·나무·폭포 등 아트는 복제하지 않았습니다.

- 새 Flat 월드: 6개 주요 Zone + 16개 개인 Plot, 회색 이동 경로, 번호/소유자 표식, 18개 상호작용 Prompt.
- 위치·크기·타입·상호작용 거리는 `config/zones.json` 한 곳에서 관리합니다. 생성기가 월드와 Luau 설정을 함께 만듭니다.
- 연못은 파란 Flat Part이며 Terrain 물을 생성하지 않습니다. 안전 Box로 보행 진입을 막고, 서버는 부두 범위·높이, 캐스팅 목표, 실제 찌 좌표와 수면 Raycast를 검사합니다.
- 이전 UI를 가져오지 않고 새 목록형 가방/단일 상세 화면과 상황별 게이지만 연결했습니다. ViewportFrame·복잡한 전환·상시 대형 패널이 없습니다. 코인/가방은 TopbarSafeInsets, 본문/게이지는 CoreUISafeInsets를 사용해 기본 UI 영역을 구분합니다.
- 기존 검증 코드를 검토하고 `Domain`, `FishingMachine`, `Catalog`, `ProfileStore`, `Lease`를 바이트 단위 그대로 재사용했습니다. 경제·확률·부화·버프 수치와 저장 스키마는 유지했습니다.
- 표시 모델은 단순 타원/구체이며 개인 프로필 데이터와 분리됩니다. 재접속 시 새로 할당된 Plot에 배치가 복원됩니다.
- 보상 어댑터와 PlotRegistry를 분리하고, 디버그 작업은 서버에서 Studio+설정값 두 조건을 확인합니다. 정상 획득과 디버그 개체/작업을 구별합니다.
- 새 빌드에는 서버 Script 1개, LocalScript 2개만 있습니다. 0.1 및 0.1.1 실행 스크립트를 중복 로드하지 않습니다.

## 정상 획득과 디버그를 구분한 검증

- **정상 규칙 연결 검사:** 디버그를 호출하지 않고 실제 FishingMachine에 시간/홀드/9회 탭을 입력했습니다. 성공 상태를 확인한 후 RewardService, Zone 권한, Domain 소비/부화를 연결했습니다. 보상 표의 각 구간을 확인하기 위해 난수 입력값을 테스트에서 고정했습니다. 이는 Studio에서 무작위 실제 낚시를 완료했다는 뜻이 아닙니다.
- **디버그 검사:** 물고기·알·사료·코인 지급, 레벨 변경, 즉시 부화를 별도로 호출했습니다. Live/StudioDebug=false에서 모든 데이터 변경이 거부되는지 검사했습니다. 지급 및 즉시 부화 결과에는 `source=studioDebug`가 남습니다.
- **영속 검사:** 기존 ProfileStore에 주입한 모의 UpdateAsync에서 재시도·오류·잠금·재접속/오프라인 부화를 확인했습니다. 실제 Roblox 클라우드 계정 접근은 수행하지 않았습니다.
- **화면 검사:** 실제 UI의 상태/입력 의도와 Layout 모듈을 검사했습니다. 픽셀 렌더링·기본 모바일 점프/이동 버튼과의 관계는 Studio/실기기 검수 대상입니다.

## 남은 실제 검증과 이후 개선

[QA_0.2.md](QA_0.2.md)의 7개 시나리오를 Studio에서 수행해야 합니다. 특히 캐스팅 착수 Raycast, 투명 안전 Box 충돌, F/터치 누르기·놓기·연타, 2인 복제, 실제 DataStore 재접속을 우선 확인하세요.

핵심 시스템 승인 후에는 Zone ID와 Floor/Console 계약을 유지하면서 실제 아트를 얹을 수 있습니다. 이후 동시 접속/최대 개체의 성능 측정, 실제 기기별 입력 보정, V2 입력 어댑터를 진행할 수 있습니다. 이번 버전은 서버가 보는 위치를 검사하지만 별도의 이동 속도/텔레포트 탐지까지 구현한 완성형 안티치트는 아닙니다.

검사 원문: `build/test-output-0.2.txt`. 소스/빌드 체크섬과 최종 커밋/PR은 전달 ZIP의 `DELIVERY.md`에 기록합니다. main 병합·Roblox 일반 공개·Robux 기능은 수행하지 않았습니다.
