| 시각 모델 | 손잡이·릴·가이드가 있는 Rod, 밝은 낚싯줄·주황 찌·곡선 비행·입질 알림, 층을 쌓은 물고기/알/동물 모델, 부화 빛점과 부드러운 펫 추종 |

## 후속 검수와 개선 우선순위

1. `QA_0.1.1.md`로 실제 Studio에서 첫 화면·저항·가방·수족관·부화·펫을 촬영하고, 텍스트나 기본 UI가 겹치는 기기별 위치를 조정합니다.
2. 16명/최대 배치 상태의 GPU·프레임률을 측정합니다. 현재 StreamingEnabled는 기존처럼 false이며, 실제 측정 뒤 모델/거리 갱신을 추가 최적화할 수 있습니다.
3. 태블릿/휴대폰에서 기본 점프·이동·핫바와의 간격, 낮은 화질에서 물·유리·그림자 가독성을 확인합니다.
4. 시각 QA 이후 필요하면 자체 제작 캐스팅 애니메이션·잔잔한 환경 음향을 추가할 수 있습니다. 이번 빌드는 외부 애니메이션/오디오 에셋을 요구하지 않습니다.

이번 구현은 Studio 승인 전 검수용입니다. Draft PR을 병합하거나 Roblox Experience를 공개하는 절차는 수행하지 않습니다.
