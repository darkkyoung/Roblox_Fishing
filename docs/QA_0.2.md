## 준비 및 공통 확인

1. 새 `FILAMENT-Fishing-0.2.rbxl` 또는 `.rbxlx`를 Studio에서 엽니다. Output 창을 열고 **Play(F5)**를 누릅니다.
2. 첫 안내의 임시 저장을 확인합니다. 가방 → ? 도움말에서 버전/조작/저장 상태를 봅니다. 기본 `StudioPersistence=false`에서는 Stop 후 초기화가 정상입니다.
3. PC 키보드/마우스, 좁은 Studio 게임 뷰포트(약 800×500), 모바일 에뮬레이터 세로 390×844와 가로 844×390에서 공통 항목을 반복합니다. 터치 실기기 검수 여부를 별도로 기록합니다.
4. **정상 루프 검수**는 새 Play 세션에서 디버그를 쓰지 않고 합니다. **빠른 기능 검수**는 가방 → ? → Studio 도구로 자료를 준비할 수 있지만, 결과 기록에 DEBUG라고 표시합니다.

- [ ] 처음 스폰하면 정면에 연못/부두, 왼쪽 아래 주황 상점, 왼쪽 위 보라 공방, 북쪽 청록 정원이 보이거나 길을 따라 찾을 수 있음.
- [ ] 건물/나무/장식/복잡한 물이 없고 파란 평면·갈색 부두·번호 슬롯만 사용함.
- [ ] 평소 UI는 코인·가방·작은 힌트만 표시. 낚시하지 않을 때 게이지 없음.
- [ ] 기본 Roblox 메뉴/채팅과 중요한 버튼이 겹치지 않음. B/가방을 열면 낚시 UI와 입력이 정리됨.
- [ ] 화면을 회전/축소해도 가방 내용은 스크롤 가능하고 주요 버튼 터치 가능. Esc/포커스 전환 후 입력이 계속 유지되지 않음.
- [ ] 캐릭터 리셋 후 Rod 재지급/장착, UI 한 개, 정상 카메라 회전·줌.
- [ ] 남쪽 부두 입구를 걸어서 통과 가능. 부두 옆/앞과 연못 둘레로 걸어가거나 점프해도 안전 Box가 진입을 막음. 파란 바닥 아래로 빠지지 않음.

## 시나리오 1 — 정상 낚시

1. 디버그 미사용 새 세션에서 부두로 걸어가 Rod를 장착합니다.
2. F를 약 1초 누르면 캐스팅 파워만 나타납니다. 놓으면 주황 찌가 파란 평면의 노출된 수면에 도착해야 합니다. 줄은 Rod 끝과 연결됩니다.
3. 기본 3~7초 후 입질 안내 → F 유지 → 50%에서 저항 → 버튼을 놓고 **4초 내 9회** 누르기/놓기 → 다시 유지합니다.
4. 100%에서 성공 안내와 보상 1개를 확인합니다. 가방의 획득 경로는 정상 낚시이고 도움말 정상 포획 수가 증가해야 합니다.
5. 다시 시도하여 저항에서 아무것도 누르지 않습니다. 실패 안내·게이지/찌 제거·보상 없음·재시도 가능을 확인합니다.
6. 스폰/상점/공방/정원/타인 Plot에서는 낚시가 시작되면 안 됩니다. 충전/입질 중 부두를 벗어나거나 Rod 해제 시 취소되어야 합니다.
7. 모바일은 오른쪽 버튼으로 같은 절차를 수행합니다. 다른 손가락으로 이동/점프하고 그 손가락을 떼어도 낚시 버튼이 잘못 해제되지 않는지 확인합니다.

- [ ] PC 정상 성공 / [ ] PC 저항 실패 / [ ] 마우스 / [ ] 터치 성공·실패
- [ ] 부두 바깥 차단 / [ ] 최소·최대 파워 착수 / [ ] 3종/알 실제 획득 기록

5% 알 확률 때문에 짧은 세션에서 알이 안 나올 수 있습니다. 정상 낚시에서 나온 종류/횟수만 기록하세요. 디버그로 지급한 알을 이 항목의 PASS 근거로 쓰지 않습니다.

**착수 거부 검수(Studio 전용):** Waiting에 들어가기 전 서버 테스트 콘솔에서 `local f=workspace.World.Zones.FishingLake.Floor; f.CanCollide=false; f.CanQuery=false`로 잠시 바꾸고 캐스팅합니다. 입질/보상으로 진행되지 않고 실패해야 합니다. 검수 후 두 속성을 모두 true로 복원하거나 Stop/Play합니다. CanQuery는 CanCollide가 false일 때 적용되므로 두 설정을 함께 변경합니다. Floor 이동으로 설정을 불일치시키면 시작 시 Zone 오류가 발생하는 것도 별도 검사할 수 있습니다.

## 시나리오 2 — 보관·회수

1. 물고기 획득 후 왼쪽 회색 길을 따라 북쪽 수족관 정원으로 갑니다.
2. 가방 상단의 `AquariumPlotNN`과 본인 표시 간판을 확인합니다. 자신의 Console에서만 E/터치 Prompt가 활성화되어야 합니다.
3. 물고기 탭 → 개체 선택 → 배치. 자기 Plot에 단순 3D 물고기가 나타나고 가방 상태가 배치 중으로 바뀌는지 확인합니다.
4. 수족관 탭 → 같은 개체 → 회수. 표시 모델이 사라지고 가방 보관 상태로 돌아와야 합니다.
5. 배치한 물고기를 상점/공방에서 소비할 수 없어야 합니다. 배치와 회수 여러 번 반복 시 모델이 중복 생성되면 안 됩니다.

## 시나리오 3 — 경제

1. 주황 FishMarket에서 E/터치 → 물고기 선택 → 판매합니다. 피라미/농어/잉어는 20/40/80코인이 증가하고 해당 ID가 제거되어야 합니다.
2. 같은 ID를 반복 판매해도 추가 코인이 지급되면 안 됩니다.

## 시나리오 4 — 알·사료·레벨·부화

1. 정상 낚시 알을 준비합니다. 빠른 기능 검수에서는 DEBUG 알/사료를 사용하되 구별합니다.
2. 내 Plot에서 알을 선택합니다. 사료 없음/기본/고급을 선택해 확률과 60/50/40초를 확인하고 **배치 버튼으로 확정**합니다.
3. 사료를 사용했다면 정확히 1개 감소하고 단순 알 모델이 나타나야 합니다. 이미 부화 중인 알은 회수/사료 재적용이 불가해야 합니다.
4. 시간이 끝나면 알 모델이 사라지고 **같은 ID의 펫 1마리**가 가방에 생겨야 합니다. 뒤늦은 갱신이나 반복 클릭으로 중복 지급되면 안 됩니다.

6. 내 Plot 수족관 탭에서 업그레이드합니다. 100/250코인, 4/7/10개, Lv.3 최대를 확인합니다. 다른 Plot과 Zone 밖에서는 업그레이드 불가입니다. 이미 배치한 알의 레벨/사료는 바뀌지 않아야 합니다.

## 시나리오 5 — 펫·버프

1. 부화한 펫을 장착합니다. 단순 구체가 따라다니고 1슬롯만 활성화되어야 합니다.
2. 장착 해제 → 캐스팅, 장착 → 새 캐스팅으로 입질/포획 변화를 비교합니다. 장착은 진행 중 낚시가 끝난 뒤 적용합니다.
3. 수달/여우/드래곤 각각 입질 −10/20/35%, 포획 +5/12/25%입니다. 입질은 난수 대기이므로 여러 번 평균을 비교하고, 포획은 같은 유지 시간으로 비교합니다.
4. 장착 해제하면 추종 개체가 사라지고 다음 낚시가 기본 계수로 돌아와야 합니다. 저항은 항상 4초/9회입니다.

4. 알 배치 → 저장 완료 → Stop → 60초 이상 대기 → 재접속 → 펫 1마리. 다시 접속해도 같은 ID/종류이고 추가 지급이 없어야 합니다.
