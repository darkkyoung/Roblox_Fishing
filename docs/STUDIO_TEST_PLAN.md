# Roblox Studio 승인 테스트 — 아직 미실행

이 문서는 실제 사용자 실행으로 채워야 하는 절차입니다. 자동 테스트 결과를 실제 플레이 결과로 대체하지 않습니다. 모든 체크박스는 현재 미확인입니다.

## 1. 준비와 첫 실행

- [ ] `build/FILAMENT-Fishing-0.1.rbxl`을 Studio에서 열고 Play(F5)를 실행합니다.
- [ ] 캐릭터, 연못, 부두, 두 작업장, 수족관, HUD가 보입니다. 낚싯대가 자동 장착됩니다.
- [ ] Output에 `[FILAMENT] Fishing PoC 0.1.0 ready. Mode: STUDIO MEMORY`가 나타납니다. 시작 시 임시 저장 안내 경고 1개는 의도된 동작입니다. 붉은 스크립트 오류는 없어야 합니다.
- [ ] 상단에 `임시 저장 · Stop 시 초기화`가 표시됩니다.
- [ ] 캐릭터를 리셋해도 낚싯대를 다시 장착하고 UI가 중복 생성되지 않습니다.

## 2. 낚시 성공과 실패

1. 낚시터로 이동합니다. F키를 약 0.5초 유지하다 놓습니다. 파워가 중간 이하에서 캐스팅되어야 합니다.
2. 한 번 더 낚시할 때 1.8초 이상 유지합니다. 이전보다 찌가 멀리 놓여야 합니다. 찌는 부두 옆 연못 안으로 보정됩니다.
3. 3~7초 후 입질 안내가 나오면 F키를 유지합니다. 게이지가 50%까지 증가해야 합니다.
4. 저항 안내 시 F키를 놓았다가 4초 안에 9번 눌렀다 떼세요. 남은 시간과 인정 횟수가 표시됩니다.
5. 저항 해제 뒤 F키를 유지하면 100%에 도달하며 개체 한 개를 받습니다.
6. 다음 낚시에서는 저항 시 아무것도 하지 마세요. 4초 뒤 실패하고 인벤토리가 증가하지 않아야 합니다.
7. 기다리는 도중 부두 밖으로 이동하거나 낚싯대를 해제하세요. 낚시가 취소되고 찌가 제거되어야 합니다.
8. 취소 버튼을 눌러도 새 아이템은 지급되지 않아야 합니다.

- [ ] 짧은·긴 캐스팅 거리 차이
- [ ] 입질·게이지·저항·최종 성공
- [ ] 제한시간 실패 시 보상 없음
- [ ] 이동·장비 해제·죽음·취소 시 정리
- [ ] 화면 버튼으로도 동일 동작

실제 낚시에서 알은 5%이므로 짧은 테스트에서 안 나올 수 있습니다. 디버그 지급은 낚시 추첨 자체를 검증하지 않습니다. 자연 획득과 테스트 지급을 별도로 기록하세요.

## 3. 물고기 활용·소유권 상태

1. 도움말의 테스트 팩을 한 번 지급합니다. 피라미·농어·잉어·알이 각각 추가되어야 합니다.
2. 내 수족관으로 이동하고 피라미를 배치합니다. 실제 물고기가 수조 안에서 움직여야 합니다.
3. 배치된 피라미는 `회수` 버튼만 표시됩니다. 판매·사료 제작을 바로 할 수 없어야 합니다.
4. 피라미를 회수합니다. 판매 상점으로 이동해 판매하면 20코인이 늘고 해당 ID가 사라져야 합니다.
5. 사료 공방에서 농어를 고급 사료로 바꾸면 고급 사료 1개가 늘고 농어가 사라져야 합니다.
6. 잉어를 기본 사료로 바꾸면 기본 사료 3개가 늘어야 합니다.
7. 작업장 밖에서는 판매·제작 요청이 거부되고 코인·개체 수가 변하지 않아야 합니다.
8. 테스트 팩을 추가 지급해 레벨 1의 수조 4칸을 채우세요. 5번째 배치는 거부되어야 합니다. 업그레이드 후 가능해야 합니다.

- [ ] 세 물고기 표시·배치·헤엄·회수
- [ ] 판매금액과 사료 수량 일치
- [ ] 같은 ID의 중복 판매·소비 불가
- [ ] 거리 검증·수용량·업그레이드 비용

## 4. 알·확률·펫 버프

1. 레벨 1에서 사료 없음·기본·고급을 선택해 알 탭의 확률을 비교합니다. 좋은 사료일수록 희귀·전설 비중이 커지고 전설은 항상 0보다 커야 합니다.
2. 사료 없이 알을 배치합니다. 60초 카운트다운, 실제 알 모델, `회수 불가` 안내가 보여야 합니다.
3. 60초 뒤 알 모델과 알 개체가 사라지고 펫 1마리가 같은 개체 ID로 나타나야 합니다.
4. 기본·고급 사료를 사용한 새 알은 각각 사료를 1개 소비하고 50초·40초 후 부화해야 합니다.
5. 알을 배치한 뒤 수조를 업그레이드해도 그 알의 표시 레벨은 이전 상태를 유지해야 합니다. 새 알부터 새 레벨이 적용됩니다.
6. 펫을 장착하면 캐릭터 주변에 모델이 나타나 따라다녀야 합니다. 다른 펫을 장착하면 이전 펫을 대체합니다.
7. 펫 없이 입질 이후 첫 50%까지의 시간을 측정합니다(기본 약 2.94초). 수달·여우·드래곤 장착 시 각각 약 2.80 / 2.63 / 2.35초입니다. 서버 프레임·통신 때문에 약간의 오차가 있습니다.
8. 입질 대기는 무작위이므로 한두 번으로 비교하지 말고 같은 펫으로 여러 번 비교합니다. 서버 버프 코드는 자동 테스트에서도 확인되었습니다.

- [ ] 60 / 50 / 40초 부화·사료 소모
- [ ] 수조 레벨·사료·시간 확률 반영
- [ ] 펫 인벤토리·1마리 장착·추종
- [ ] 실제 낚시 속도 변화

무작위 결과이므로 펫 3종을 짧은 수동 실험에서 모두 얻는다고 보장하지 않습니다. 전체 결과의 도달 가능성은 Luau 자동 테스트로 확인했습니다. 실제 모델은 충분한 디버그 알을 부화하거나 서버 디버거로 관찰하세요.

## 5. 저장·오프라인 부화

README의 비공개 Experience·API 접근·`StudioPersistence=true` 절차를 먼저 수행합니다. **기본 임시 저장 모드로 이 테스트를 통과했다고 기록하면 안 됩니다.**

- [ ] 새 세션의 코인·사료·물고기·수조 레벨·배치·펫 장착 상태 저장
- [ ] 정상 Stop/Play 뒤 모두 복구
- [ ] 부화 중 Stop → 60초 이상 대기 → Play → 펫 1개 지급
- [ ] 다시 Stop/Play → 같은 펫 유지, 재추첨·중복 없음
- [ ] Studio API 접근을 끄고 새 Play → 오류가 명시되고 빈 프로필로 덮어쓰지 않음
- [ ] 다시 API 접근을 켜면 기존 데이터가 유지됨

진행 중 실제 저장 실패 주입은 격리된 테스트 Experience에서만 수행하세요. 자동 저장 어댑터 테스트에는 쓰기 전 실패, 쓰기 성공 후 응답 유실, 모든 재시도 실패가 포함되어 있습니다. 실제 Roblox DataStore 제한·네트워크 오류는 별도 검증 대상입니다.

## 6. 로컬 2인 테스트

1. 기본 임시 모드로 되돌립니다(자동 테스트 계정의 영속 데이터 혼동 방지).
2. Studio의 **Test → Server & Clients / Local Server**에서 플레이어 수를 **2**로 설정하고 시작합니다. UI 명칭은 Studio 버전에 따라 조금 다를 수 있습니다.
3. 각 클라이언트에서 테스트 팩을 지급하고 `내 수족관`으로 이동합니다.
4. 서로 다른 수족관과 이름표가 할당되어야 합니다. 각자 물고기를 배치한 후 상대 수조에도 모델이 보이는지 확인합니다.
5. 상대 수조 앞에서 자신의 개체를 배치하려 하면 `내 수족관으로 이동` 안내가 나와야 합니다.
6. 상대 개체를 가방에서 조회하거나 선택할 수 없어야 합니다.
7. 한 명이 펫을 장착하면 두 화면에서 그 플레이어를 따라다녀야 합니다.
8. 한 클라이언트를 종료하면 해당 수조가 비고 남은 플레이어의 개체·낚시에 영향이 없어야 합니다.

- [ ] 두 명의 수조·가방·코인 분리
- [ ] 상대 모델 관람·조작 불가
- [ ] 동시 낚시와 서로 다른 보상
- [ ] 접속 해제 시 수조·찌 정리

추가 보안 확인: Client Command Bar에서 자기 `LocalPlayer`로 상대 아이템 ID를 포함해 `ReplicatedStorage.Remotes.Action:FireServer("sell", "상대의 실제 아이템 ID")`를 보내도 상대 데이터가 변하면 안 됩니다. ID는 Server 디버거에서 확인할 수 있으며, 임의의 존재하지 않는 ID만 보내는 것으로 소유권 테스트를 대체하지 마세요. 정상 지급 없는 직접 `equip`, `place`, `craft` 요청도 거부되어야 합니다.

## 7. PC·모바일

Studio Device Emulator에서 아래 크기에 근접한 프리셋으로 테스트합니다. 자동 테스트는 외곽 크기 계산만 검증했으므로 텍스트·터치·카메라는 여기서 확인해야 합니다.

| 환경 | 확인할 사항 |
|---|---|
| PC 1920×1080 / 1280×720 | F키, B키, R키, 마우스 버튼, 기본 캐릭터 이동 |
| 모바일 세로 약 375×812 / 390×844 | 가로 이동 메뉴 스크롤, 가방 세로 스크롤, 긴 버튼 글자, 조이스틱·점프 버튼과 겹침 |
| 모바일 가로 약 812×375 / 844×390 | 가방 닫기, 콘텐츠 스크롤, 캐스팅·저항 버튼이 화면 내부에 존재 |
| 최소 폭 320 | 한국어·영어 텍스트 줄바꿈, 도움말 전체 스크롤 |

- [ ] 손가락 유지 → 떼기로 캐스팅
- [ ] 입질 후 유지 → 떼고 연타 → 다시 유지
- [ ] 화면 밖으로 손가락을 뗐을 때 유지 입력이 멈춤
- [ ] 두 손가락 조작 중 잘못된 연타·버튼 고정 없음
- [ ] 창 포커스를 잃으면 입력 중지
- [ ] 언어 전환 후 넘침 없음

에뮬레이터 통과 후에도 실제 Windows Roblox 클라이언트·휴대폰 접속 검증은 별도입니다. 비공개 테스터 권한으로만 접속하고 일반 공개는 하지 마세요.
